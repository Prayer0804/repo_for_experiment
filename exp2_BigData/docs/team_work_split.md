# 四人团队分工

## 成员 A：数据工程

- 负责数据下载、样例数据生成和配置维护。
- 负责 Bronze 层和 Silver 层处理。
- 负责 schema 检查、数据质量报告和可复现样例数据。

## 成员 B：数据分析

- 负责 Gold 层聚合表设计。
- 负责离线分析输出。
- 解释时段规律、热点区域、高频 OD 路线和支付行为。

## 成员 C：算法建模

- 负责需求预测特征工程。
- 负责训练基线模型和改进模型。
- 负责模型指标、模型文件和模型报告维护。

## 成员 D：可视化与交付

- 负责 ECharts 可视化大屏。
- 负责前端数据导出。
- 负责演示流程、README 和最终交付清单。
